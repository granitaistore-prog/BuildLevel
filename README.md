# Будівельний рівень (BuildLevel)

Простий будівельний рівень для Android (розроблено під Samsung Galaxy A25, працює на Android 8.0+).
Використовує акселерометр телефону. Без реклами, без інтернету, без зайвих дозволів.

## Можливості
- **Площина** – телефон лежить на поверхні, бульбашка по двох осях.
- **Стіна** – телефон притиснутий до стіни, перевірка вертикалі (виска) і нахилу вперед/назад.
- **Лінійка** – горизонталь по одній осі (телефон ребром на полиці, дошці тощо), велике число кута.
- Кути в **градусах** або **відсотках** ухилу.
- **Калібрування** (короткий тап – задати нуль, довгий тап – скинути).
- **Фіксація** показів.
- Колір стає зеленим і телефон коротко вібрує, коли відхилення менше 0,5°.
- Екран не гасне; працює у портретній та альбомній орієнтації.

## Збірка
**Android Studio:** `File → Open` → вибрати цю папку → `Run ▶` (телефон з увімкненим налагодженням по USB).

**GitHub Actions:** після пуша в `main` APK збирається автоматично –
вкладка *Actions* → останній запуск → *Artifacts* → `BuildLevel-debug-apk`.

## Калібрування
Поклади телефон на заздалегідь перевірену рівну поверхню, обери режим, натисни «Калібрувати».
Калібрування запам'ятовується окремо для кожного режиму й орієнтації екрана.
